📄 Help - Claims Report

1. Purpose of this form

The Claims Report form allows users to view, filter, and print detailed reports of all registered claims in the AseguraYa system. Reports can be exported as PDF documents for audits, analytics, or monthly summaries.

2. Screen layout

  • Main grid: displays all registered claims with date, description, and value information.
  • Date filter: allows selecting claims by their occurrence date.
  • Description: dropdown menu to filter claims by type (e.g., theft, fire, collision, etc.).
  • Filter: applies the selected filters locally without querying the database.
  • Clear Filters: restores the full list of claims.
  • Print: generates a formatted PDF report including totals and averages.

3. Filtering process

  1. Select a date and/or description to narrow down results.
  2. Click Filter to display matching records.
  3. Click Clear Filters to reset the view.
💡 Tip: Filtering is performed in memory, which makes it fast and efficient.

4. PDF generation

When clicking Print, the system creates a ClaimsReport.pdf file containing:

  • A title and generation timestamp.
  • All visible data columns from the table.
  • A summary with total number of claims and average value.

5. Validations and security

  • No PDF is generated if there are no records loaded.
  • The report is saved in the location chosen by the user.
  • Each report generation is logged in the system’s audit trail.

6. Audit log

Every report creation is recorded, including the user ID, form name, and timestamp, ensuring full traceability.

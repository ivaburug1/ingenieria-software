🛠️ Ayuda - Modificar Seguro

1. Propósito del formulario

El formulario Modificar Seguro permite actualizar los datos de una póliza ya existente en el sistema AseguraYa. A través de esta pantalla se pueden consultar las coberturas, cambiar el plan asociado y extender la vigencia de una póliza.

2. Estructura de la pantalla

  • Número de póliza: campo para ingresar el número de la póliza que se desea modificar.
  • Botón con ícono de ojo: permite visualizar los datos actuales de la póliza seleccionada.
  • Producto: muestra el tipo de seguro asociado a la póliza (vida, auto, hogar, etc.).
  • Planes: muestra los planes y coberturas disponibles para el producto seleccionado.
  • Botones:
    • Aceptar: guarda los cambios realizados en la póliza.
    • Cancelar: cierra el formulario sin realizar modificaciones.

3. Proceso de modificación

  1. Ingresar el Número de póliza y presionar el botón del ojo 👁️.
  2. El sistema mostrará los datos actuales de la póliza, incluyendo producto, plan y coberturas.
  3. Seleccionar un nuevo Plan si se desea cambiarlo.
  4. Verificar las coberturas disponibles y confirmar los cambios con Aceptar.
  5. La póliza se actualizará y se registrará un evento en la bitácora del sistema.
💡 Consejo: el sistema recalcula automáticamente el dígito verificador (DVH/DVV) al modificar una póliza, garantizando la integridad de los datos.

4. Validaciones y errores comunes

  • El número de póliza debe ser un valor numérico válido.
  • No se puede modificar una póliza inexistente.
  • El campo Producto no puede quedar vacío.

5. Auditoría y trazabilidad

Cada modificación de póliza queda registrada en la bitácora de eventos, incluyendo la fecha, el usuario y los datos actualizados. Esto garantiza la trazabilidad completa de los cambios realizados.

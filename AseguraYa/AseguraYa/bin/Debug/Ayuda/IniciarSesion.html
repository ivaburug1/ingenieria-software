🔐 Ayuda - Iniciar Sesión

1. Descripción general

Este formulario permite a los usuarios registrados acceder al sistema AseguraYa ingresando su DNI y contraseña. Se aplican mecanismos de seguridad para validar las credenciales, gestionar intentos fallidos y bloquear usuarios después de tres errores consecutivos.

2. Objetivos principales

  • Permitir el acceso al sistema solo a usuarios válidos y activos.
  • Aplicar validaciones de formato y seguridad (SHA256 para contraseñas).
  • Bloquear automáticamente usuarios con múltiples intentos fallidos.
  • Registrar todos los eventos en la bitácora del sistema.
  • Iniciar sesión con idioma personalizado del usuario.

3. Funcionamiento del formulario

  1. El usuario ingresa su DNI y contraseña.
  2. El sistema verifica que ambos campos estén completos y que el DNI sea numérico.
  3. Se busca el usuario en la base de datos.
  4. Si existe, se calcula el hash SHA256 de la contraseña ingresada y se compara con la almacenada.
  5. Si coinciden:
    • Se inicia la sesión y se crea una instancia Singleton del usuario activo.
    • Se cargan sus permisos, idioma y perfil.
    • Se registran los eventos de acceso en la bitácora.
  6. Si no coinciden:
    • Se incrementa el contador de intentos.
    • Al tercer intento fallido, el usuario queda bloqueado automáticamente.

4. Validaciones

  • DNI: debe ser numérico (valida mediante expresión regular).
  • Contraseña: no puede estar vacía.
  • Ambos campos deben completarse antes de iniciar sesión.

5. Mensajes del sistema

✅ Sesión iniciada correctamente: el usuario accede al sistema sin errores.
⚠️ Usuario o contraseña incorrectos: se informa el número de intentos restantes.
⚠️ Usuario bloqueado: luego de 3 intentos fallidos, el acceso queda bloqueado.
⚠️ Usuario desactivado: la cuenta existe pero está inactiva administrativamente.
⚠️ Falta ingresar datos: alguno de los campos se encuentra vacío.
⚠️ Error inesperado: se muestra un mensaje genérico con la excepción capturada.

6. Casos especiales

  • Si el sistema detecta que la base no pasó la verificación de integridad (DVH/DVV), no se permite el inicio de sesión.
  • Los usuarios con permiso de Administrador General acceden directamente al módulo de reparación del sistema.
  • Si el usuario tiene activado el cambio obligatorio de contraseña, se abre automáticamente el formulario _686DPfrmCambiarContraseña.

7. Errores comunes

  • Formato de DNI no válido → el campo contiene letras u otros caracteres no numéricos.
  • NullReferenceException → puede ocurrir si el idioma o las dependencias de inicio no se cargan correctamente.
  • UsuarioBloqueado → se intenta iniciar sesión con una cuenta ya bloqueada.
  • ErrorDB → error interno en la conexión o recuperación de datos del perfil.

8. Consejos de uso

  • Verificar que el idioma del usuario esté correctamente configurado para evitar mensajes no traducidos.
  • No compartir credenciales personales.
  • Si la cuenta queda bloqueada, contactar con el Administrador General para su desbloqueo.

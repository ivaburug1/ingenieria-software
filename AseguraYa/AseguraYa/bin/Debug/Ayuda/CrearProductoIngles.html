🛡️ Help - Create Insurance Product

1. Purpose of this form

This module allows you to manage products, plans, and coverages in the AseguraYa system. You can create new insurance products, link plans to them, and define specific coverages.

2. Mode: “Create product”

  • Select the “Create product” radio button.
  • Enter a valid name in the Product field (letters only).
  • Click Create product to save it.
💡 Tip: The system will automatically check if the product already exists and register the action in the event log.

3. Mode: “Group insurance”

  • Select an existing product from the Product dropdown list.
  • Enter the plan details:
    • Franchise: deductible amount.
    • Premium: cost of the plan.
  • Use Create plan to generate a new one, or Associate coverage to link an existing one.
⚙️ When you select a plan in the list, its coverages will appear in the panel on the right.

4. Coverage management

  • Fill in the Description and Insured Amount fields.
  • Click Create coverage to add it to the selected plan.
⚠️ Duplicate coverages with the same description and insured amount are not allowed.

5. Automatic validations

The system performs real-time validations:

  • Text fields: letters only.
  • Numeric fields: numbers only.
  • Checks for duplicate products, plans, or coverages.

6. Data integrity and security

Each creation or modification automatically recalculates the DVH/DVV (Verification Digits) and registers an audit event to ensure data integrity and traceability.

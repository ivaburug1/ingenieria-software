👥 Ayuda - Gestión de Clientes

1. Objetivo del formulario

Este módulo permite gestionar los clientes registrados en el sistema AseguraYa. Desde aquí podrás crear nuevos clientes, modificarlos, eliminarlos, encriptar sus correos electrónicos y realizar copias XML de respaldo.

2. Registrar Cliente

  • Presioná “Registrar Cliente” para ingresar en modo creación.
  • Completá todos los campos obligatorios:
    • DNI – solo números.
    • Nombre y Apellido – solo letras.
    • Email – debe tener formato válido.
    • Domicilio – dirección del cliente.
    • Código Postal – solo números.
  • Hacé clic en Aplicar para guardar el nuevo cliente.
💡 El sistema validará automáticamente que el cliente no exista y calculará su DVH/DVV.

3. Modificar Cliente

  • Seleccioná un cliente en la grilla superior.
  • Presioná “Modificar Cliente” para activar el modo edición.
  • Actualizá los datos deseados y hacé clic en Aplicar.
⚙️ El campo DNI no se puede editar para evitar duplicados. Todos los cambios quedan registrados en el historial de eventos.

4. Eliminar Cliente

  • Seleccioná un cliente activo en la tabla.
  • Presioná “Eliminar Cliente” y luego Aplicar.
  • El sistema realiza una eliminación lógica (el cliente no se borra físicamente, solo se desactiva).

5. Encriptar/Desencriptar Emails

El botón “Mostrar Mails” alterna entre mostrar los correos encriptados o desencriptados mediante el algoritmo AES-256. Esto protege los datos sensibles de los clientes almacenados en la base.

6. Serialización / Deserialización

  • Serializar: Guarda los clientes seleccionados en un archivo XML local.
  • Deserializar: Carga y visualiza los datos desde un archivo XML.
📁 Ideal para generar respaldos o intercambiar datos con otros sistemas.

7. Validaciones automáticas

  • Campos alfabéticos (nombre, apellido, domicilio) solo permiten letras.
  • Campos numéricos (DNI, código postal) solo aceptan números.
  • El email se valida al salir del campo o al guardar.

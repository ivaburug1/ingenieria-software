👤 Ayuda - Crear Perfil de Usuario

1. Propósito del formulario

Esta sección permite crear y gestionar perfiles de usuario en el sistema AseguraYa. Un perfil agrupa familias y permisos que determinan qué puede hacer cada usuario dentro de la plataforma.

2. Creación de un nuevo perfil

  • Ingresá el nombre del perfil en el campo Nombre (solo letras).
  • Presioná Crear Perfil para iniciar la creación.
  • El perfil aparecerá en el panel central como “Perfil por crear”.
💡 Si el nombre del perfil ya existe, el sistema mostrará una advertencia y no permitirá continuar.

3. Agregar familias al perfil

  • Seleccioná una o más familias desde el panel Familias.
  • Presioná Agregar Familia para incluirlas en el perfil.
  • Todos los permisos que pertenezcan a esa familia se agregarán automáticamente.
⚙️ El sistema evita familias duplicadas o permisos repetidos.

4. Agregar permisos individuales

  • Seleccioná un permiso desde el panel derecho Permisos.
  • Presioná Agregar Permiso para incluirlo directamente en el perfil.
  • Los permisos ya incluidos mediante una familia no se pueden volver a agregar.

5. Guardar el perfil

  • Una vez agregadas todas las familias y permisos deseados, presioná Crear Perfil.
  • El perfil se guardará en el sistema y aparecerá en la lista de Perfiles.
  • La operación se registrará en el historial de eventos del sistema para trazabilidad.

6. Edición o eliminación de componentes

Los perfiles existentes pueden modificarse desde el panel Perfiles:

  • Desasignar Familia: elimina una familia completa del perfil seleccionado.
  • Desasignar Permiso: elimina un permiso individual.
  • Si el perfil queda sin componentes, se eliminará automáticamente.

7. Integridad y auditoría de datos

Cada modificación recalcula automáticamente los DVH/DVV (dígitos verificadores) y registra un evento de auditoría, garantizando la integridad y seguridad de la base de datos.

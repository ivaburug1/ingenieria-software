📊 Help - Policies Management

1. Purpose of this form

The Policies form allows users to view, filter, analyze, and export insurance policy information from the AseguraYa system. It also provides real-time charts showing policy status and best-selling products.

2. Main components

  • Bar chart: displays the top 3 best-selling insurance products.
  • Pie chart: shows the ratio between active and inactive policies.
  • Data grid: lists all registered policies, including plan, holder, and status.
  • Filters: allow searching by state, insurance type, premium, franchise, policy number, or expiration date.
  • “Filter” button: applies the selected filters.
  • “Print selection” button: generates a PDF version of the selected policy.
  • “Print” button: exports the full report with data and charts to PDF.

3. Charts

  • The bar chart displays the 3 most sold products.
  • The pie chart compares active vs inactive policies.
  • Both charts are updated automatically when filters are applied.

4. PDF Export

The system can export a complete report in PDF format, including:

  • All visible policies from the grid.
  • Bar chart (top sales).
  • Pie chart (status distribution).
  • Translated headers and values according to the active language.
💡 Tip: rows with expired policies appear in red for easy identification.

5. Validations

  • The policy number field accepts only numeric values.
  • Filters must be correctly filled to obtain results.
  • If no row is selected, the system will prompt the user before printing.

6. Audit log

Every print or export action is logged in the system’s event module, including the user ID, action, and timestamp.

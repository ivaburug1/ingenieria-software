👤 Help - Create User Profile

1. Purpose of this form

This section allows you to create and manage user profiles in the AseguraYa system. A profile groups families and permissions that define what each user can do in the platform.

2. Creating a new profile

  • Enter the profile name in the Name field (letters only).
  • Click Create Profile to initialize the creation.
  • The profile will appear in the middle panel as "Profile to create".
💡 If the profile name already exists, the system will display a warning and block creation.

3. Adding families to the profile

  • Select one or more families from the Families panel.
  • Click Add Family to include them in the profile.
  • All permissions belonging to that family will be automatically added.
⚙️ The system prevents duplicated families or repeated permissions.

4. Adding individual permissions

  • Select a permission from the right panel Permissions.
  • Click Add Permission to include it directly in the profile.
  • Permissions already included through a family cannot be added again.

5. Saving the profile

  • Once all desired families and permissions are added, click Create Profile.
  • The profile will be saved in the system and appear in the Profiles list.
  • The operation will be logged in the system event registry for traceability.

6. Editing or removing components

Existing profiles can be modified from the Profiles panel:

  • Unassign Family: Removes a complete family from the selected profile.
  • Unassign Permission: Removes an individual permission.
  • If the profile has no components left, it will be automatically deleted.

7. Data integrity and audit

Each modification triggers recalculation of DVH/DVV (verification digits) and registers an audit event, ensuring consistency and security across the database.

🛡️ Ayuda - Crear Producto de Seguro

1. Objetivo del formulario

Este módulo permite gestionar los productos, planes y coberturas del sistema AseguraYa. Desde aquí podés crear nuevos seguros, asociar planes a productos y definir coberturas específicas.

2. Modo “Crear producto”

  • Activá el radio botón “Crear producto”.
  • Completá el campo Productos con un nombre válido (solo letras).
  • Presioná Crear producto para guardarlo.
💡 Consejo: El sistema validará automáticamente que el producto no exista y registrará el evento en el historial.

3. Modo “Agrupar seguro”

  • Seleccioná un producto existente en el combo Productos.
  • Ingresá los datos del plan:
    • Franquicia: monto deducible.
    • Prima: costo del plan.
  • Usá Crear plan para generar uno nuevo o Asociar cobertura para vincularlo.
⚙️ Al seleccionar un plan en la lista, se mostrarán sus coberturas en el panel derecho.

4. Gestión de coberturas

  • Completá la Descripción y la Suma asegurada.
  • Presioná Crear cobertura para agregarla al plan seleccionado.
⚠️ No se permite duplicar coberturas con la misma descripción y suma asegurada.

5. Validaciones automáticas

El sistema realiza validaciones en tiempo real:

  • Campos de texto: solo letras.
  • Campos numéricos: solo números.
  • Verificación de duplicados en productos, planes y coberturas.

6. Seguridad e integridad

Cada acción de creación o modificación recalcula el DVH/DVV (Dígito Verificador) y genera un evento de auditoría para asegurar la integridad de los datos.

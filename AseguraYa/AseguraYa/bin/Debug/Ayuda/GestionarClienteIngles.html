👥 Help - Client Management

1. Purpose

This module allows you to manage registered clients in the AseguraYa system. You can create, edit, or logically delete clients, encrypt emails, and export or import them as XML files.

2. Register Client

  • Click “Register Client” to enter creation mode.
  • Fill in all required fields:
    • DNI – numbers only.
    • Name and Surname – letters only.
    • Email – must be valid.
    • Address and Postal Code.
  • Press Apply to save.

3. Modify Client

  • Select a client from the list and click “Modify Client”.
  • Edit the desired fields and press Apply.

4. Delete Client

  • Select a client and click “Delete Client”.
  • Press Apply to perform a logical deletion.

5. Encrypt/Decrypt Emails

The “Show Mails” button toggles between showing encrypted and decrypted client emails (AES-256 algorithm).

6. Serialization / Deserialization

  • Serialize: Exports selected clients as XML.
  • Deserialize: Imports clients from an XML file.

7. Automatic validations

  • Alphabetic fields (name, surname, address) accept letters only.
  • Numeric fields (DNI, postal code) accept digits only.
  • Email is validated automatically.

🧾 Ayuda - Generar Contratación de Pólizas

1. Propósito del formulario

El formulario Generar Contratación permite crear una nueva póliza para un cliente, seleccionando el producto, plan y coberturas correspondientes. Si el cliente no existe, el sistema ofrece registrarlo. Si existen datos faltantes (como dirección o tarjeta), se solicitarán antes de finalizar.

2. Estructura de la pantalla

  • DNI: identifica al cliente. Si no existe, se abrirá la ventana de registro básico.
  • Producto: lista de seguros disponibles.
  • Planes: muestra los planes asociados al producto seleccionado.
  • Coberturas: detalla las coberturas que ofrece cada plan.
  • Botones:
    • Aceptar: confirma la contratación y genera la póliza.
    • Cancelar: cierra la ventana sin guardar cambios.

3. Flujo completo de contratación

  • 1️⃣ Ingresá el DNI del cliente.
  • 2️⃣ Si el cliente no existe, se abrirá Registrar Cliente (DNI, Nombre, Apellido).
  • 3️⃣ Seleccioná el Producto deseado y luego un Plan.
  • 4️⃣ Verificá las Coberturas asociadas al plan.
  • 5️⃣ Si faltan datos del cliente, se abrirá Datos Extra (Email, Domicilio, Código Postal, Medio de pago, Tarjeta).
  • 6️⃣ Al presionar Aceptar, se genera la póliza y se imprime automáticamente.
💡 Consejo: verificá que el cliente tenga email y domicilio cargados antes de aceptar, para evitar interrupciones.

4. Ventana “Registrar Cliente”

Si el cliente no existe, se abre una ventana para registrar su información básica. Solo se requiere DNI, nombre y apellido. Luego se puede continuar con la contratación.

5. Ventana “Datos Extra”

Si el cliente ya existe pero le faltan datos (email, dirección, medio de pago o tarjeta), el sistema abrirá esta pantalla para completarlos antes de generar la póliza.

6. Resultado final

Una vez confirmada la operación, se genera un registro de la póliza en la base de datos, se imprime el documento en formato PDF y el evento se registra automáticamente en la bitácora del sistema.

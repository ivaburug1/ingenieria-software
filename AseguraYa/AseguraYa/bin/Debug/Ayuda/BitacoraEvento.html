📊 Ayuda - Bitácora de eventos

1. Propósito del formulario

La Bitácora de eventos registra todas las acciones realizadas dentro del sistema AseguraYa. Permite visualizar qué usuarios ejecutaron operaciones, en qué módulo, cuándo y con qué nivel de criticidad.

2. Estructura de la pantalla

  • Cuadro principal: muestra los registros de eventos con su fecha, usuario, módulo y criticidad.
  • Fechas desde/hasta: acotan el rango temporal de los eventos mostrados.
  • Módulo: filtra por la parte del sistema donde ocurrió la acción (por ejemplo, Login, Perfiles, Clientes, etc.).
  • Criticidad: filtra los eventos según su nivel de importancia o gravedad (1 = baja, 3 = alta).
  • DNI / Nombre / Apellido: permiten identificar al usuario responsable del evento seleccionado.
  • Botones:
    • Filtrar: aplica los filtros seleccionados.
    • Limpiar Filtro: muestra nuevamente todos los registros sin restricciones.
    • Imprimir: exporta la bitácora actual en formato PDF.
💡 Consejo: podés combinar los filtros de fecha, módulo y criticidad para encontrar rápidamente eventos específicos.

3. Filtro por criterios

  • Usá las fechas Desde y Hasta para acotar el período de búsqueda.
  • Seleccioná un módulo o nivel de criticidad para refinar los resultados.
  • Ingresá un DNI si querés ver los eventos realizados por un usuario en particular.

4. Exportación a PDF

Al presionar “Imprimir”, el sistema genera un archivo PDF con todos los registros visibles. Este documento puede usarse para auditorías o reportes.

⚙️ Cada exportación a PDF queda registrada en la bitácora de auditoría con el usuario y fecha de generación.

5. Integridad y trazabilidad

Cada evento se guarda automáticamente con un nivel de criticidad y se asocia al usuario logueado. De esta manera, el sistema garantiza la trazabilidad completa de las acciones realizadas en todas las capas.

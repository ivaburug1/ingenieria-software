📊 Help - Event Log

1. Purpose of this form

The Event Log keeps a detailed record of every action performed within the AseguraYa system. It allows administrators to see which users executed operations, in which module, at what time, and with what level of severity.

2. Screen structure

  • Main grid: displays all event records, including date, user, module, and severity.
  • From / To dates: limit the time range of displayed events.
  • Module: filters by the part of the system where the event occurred (e.g., Login, Profiles, Clients, etc.).
  • Severity: filters events by their importance or level (1 = low, 3 = high).
  • DNI / Name / Last name: identify the user responsible for a selected event.
  • Buttons:
    • Filter: applies the selected filters.
    • Clear Filter: restores all records without restrictions.
    • Print: exports the current log view to a PDF file.
💡 Tip: combine date, module, and severity filters to quickly locate specific events.

3. Filtering by criteria

  • Use the From and To dates to narrow the search period.
  • Select a module or severity level to refine your results.
  • Enter a DNI to view only the events performed by a particular user.

4. Exporting to PDF

When pressing “Print”, the system generates a PDF file containing all currently visible records. This file can be used for audits or reporting.

⚙️ Every PDF export is automatically recorded in the audit log, including the user and generation date.

5. Integrity and traceability

Each event is automatically stored with a severity level and linked to the logged-in user. This ensures full traceability of all actions performed across every module of the application.

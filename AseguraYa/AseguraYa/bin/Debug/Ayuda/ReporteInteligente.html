📈 Ayuda - Recomendación de Aumento

1. Propósito de este formulario

El formulario Recomendación de Aumento permite analizar clientes con una alta cantidad de siniestros y, si corresponde, aplicar un aumento porcentual en la cuota mensual de su póliza. También permite filtrar datos y generar un reporte en PDF con los resultados visibles.

2. Estructura de la pantalla

  • Área de filtros (parte superior):
    • DNI: filtra por número de documento del cliente.
    • Cuota Desde / Cuota Hasta: define un rango de valores para la cuota mensual.
    • Cantidad de Siniestros: número mínimo de siniestros para mostrar un cliente.
    • Botones “Filtrar” y “Limpiar Filtro”: aplican o restablecen los filtros.
  • Grilla principal: Muestra los resultados. Las columnas suelen ser:
    • DNI
    • Nombre del cliente
    • Número de póliza
    • Cuota mensual actual
    • Cantidad de siniestros
  • Botones de acción (parte inferior):
    • Aumentar Cuota: aplica un aumento porcentual a la póliza seleccionada.
    • Imprimir: genera un archivo PDF con los datos visibles en pantalla.
💡 Consejo: combiná los filtros para encontrar clientes con mayor riesgo (alta cuota + muchos siniestros) antes de aplicar un aumento.

3. Cómo aplicar un aumento en la cuota

  • Seleccioná un cliente de la grilla principal.
  • Hacé clic en “Aumentar Cuota”.
  • El sistema solicitará un porcentaje para el aumento (por ejemplo, 10%).
  • Si el valor no es numérico, el sistema mostrará un mensaje de error.
  • Si ingresás un valor válido, se mostrará una ventana con:
    • DNI del cliente
    • Número de póliza
    • Cuota actual
    • Porcentaje aplicado
    • Nueva cuota resultante
  • Si confirmás, el sistema actualizará la cuota de la póliza en la base de datos y recalculará los dígitos verificadores (DVH/DVV).
  • La grilla se actualizará automáticamente.
⚠️ Si no seleccionás ninguna fila, el sistema pedirá que elijas un cliente antes de continuar.

4. Filtrar y limpiar resultados

  • Usá DNI para buscar un cliente en particular.
  • Utilizá Cuota Desde / Hasta para acotar el rango de cuotas.
  • Definí una Cantidad mínima de siniestros para ver sólo los clientes más riesgosos.
  • Hacé clic en “Filtrar” para aplicar todos los criterios.
  • Hacé clic en “Limpiar Filtro” para volver a ver la lista completa.

5. Exportar el reporte a PDF

Al presionar “Imprimir”, el sistema genera un archivo PDF en tu Escritorio con todos los registros visibles en la pantalla. El reporte incluye:

  • El nombre del sistema (AseguraYa)
  • Fecha y hora de generación
  • Una tabla con la misma información que muestra la grilla
📂 El nombre del archivo contiene la fecha y hora, lo que facilita su archivado.

6. Validaciones y mensajes del sistema

  • DNI, Cuota Desde, Cuota Hasta y Cantidad de Siniestros aceptan solo números. Si ingresás letras o símbolos, el sistema limpiará el campo y mostrará una advertencia.
  • Si ingresás un porcentaje no válido, se mostrará un mensaje de error.
  • Si ocurre un error al generar el PDF, se mostrará un detalle técnico.

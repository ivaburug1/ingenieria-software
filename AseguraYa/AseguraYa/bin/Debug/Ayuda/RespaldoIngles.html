💾 Help - Backup Management

1. Purpose of this form

The Backup Management window allows users to create and restore database backups for the AseguraYa system. Its purpose is to ensure data integrity and enable recovery in case of system failures.

2. Screen structure

  • BackUP: creates a full database backup in a .bak file.
  • Restore: allows restoring a previous backup by selecting the desired file.

3. Backup process

  • Click BackUP to choose where to save the backup file.
  • The system generates a file named BCK_YYYYMMDD_HHmmss.bak.
  • The event is automatically logged in the system’s audit record.
💡 Tip: store backups in a secure or external location for greater protection.

4. Restore process

  • Click Restore and select the .bak backup file to restore.
  • The system will replace the current database with the data from the selected backup.
  • Once completed, a confirmation message will appear on screen.
⚠️ Warning: restoring a backup will overwrite all current data with the selected backup file.

5. Logging and traceability

Every backup and restore operation is automatically recorded with the date, user, and action type, ensuring full traceability of the system’s database recovery activities.

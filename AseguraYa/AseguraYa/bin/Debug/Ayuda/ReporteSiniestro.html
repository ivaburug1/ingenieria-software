📄 Ayuda - Reporte de Siniestros

1. Propósito del formulario

El formulario Reporte de Siniestros permite consultar, filtrar e imprimir reportes con todos los siniestros registrados en el sistema AseguraYa. Incluye opciones para generar informes detallados en formato PDF, útiles para auditoría o análisis mensual.

2. Estructura de la pantalla

  • Tabla principal: muestra todos los siniestros registrados, con información como código, fecha, descripción y valor.
  • Fecha: permite filtrar los siniestros ocurridos en una fecha específica.
  • Descripción: lista desplegable que permite seleccionar el tipo de siniestro (por ejemplo, robo, incendio, choque, etc.).
  • Filtrar: aplica los filtros seleccionados sin necesidad de consultar la base de datos nuevamente.
  • Limpiar Filtros: restablece la grilla y muestra todos los registros nuevamente.
  • Imprimir: genera un reporte PDF con los resultados filtrados y un resumen general.

3. Proceso de filtrado

  1. Seleccionar una fecha y/o una descripción desde el menú desplegable.
  2. Presionar el botón Filtrar para ver los resultados en pantalla.
  3. Si se desea volver a ver todos los siniestros, presionar Limpiar Filtros.
💡 Consejo: el filtrado se realiza en memoria, sin consultar la base de datos, por lo que es rápido y eficiente.

4. Generación del PDF

Al presionar Imprimir, el sistema genera automáticamente un archivo ReporteSiniestros.pdf con:

  • Encabezado con título y fecha de generación.
  • Tabla con todas las columnas visibles en el formulario.
  • Resumen al final con el total de siniestros y el valor promedio.

5. Validaciones y seguridad

  • Si no hay registros cargados, el sistema no permite generar el PDF.
  • El archivo se guarda en la ubicación seleccionada por el usuario.
  • Cada generación de reporte se registra en la bitácora de eventos.

6. Auditoría

El sistema registra cada vez que un usuario genera un reporte, incluyendo su DNI, el nombre del formulario y la fecha de acción.

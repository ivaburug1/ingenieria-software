👤 Help - User Management

1. Purpose

This module allows you to manage all system users in AseguraYa: creation, edition, activation/deactivation, unlocking, and role assignment. It also provides filtering options to display users by status or role.

2. Create User

  • Click “Create” to enter creation mode.
  • Fill in the required fields:
    • DNI – numbers only.
    • Name and Surname – letters only.
    • Email – valid format required.
    • Role – choose from dropdown.
  • Press Apply to save.
💡 The system auto-generates username (name.surname) and password (dni.surname), stored as a SHA-256 hash.

3. Modify User

  • Select a user from the grid.
  • Click “Modify”, edit the fields, and press Apply.

4. Unlock User

  • Select a blocked user.
  • Click “Unlock” then Apply.
  • The default password will be restored and login attempts reset.

5. Activate / Delete User

  • Click “Activate / Delete” to toggle the user’s active state.
  • This is a logical deletion – data remains in the system but the account is disabled.

6. Filter Users

  • Use dropdown filters:
    • Activated/Deactivated
    • Blocked Users
    • Role
  • Click Filter to apply.

7. Automatic validations

  • Real-time validation for numeric and text fields.
  • Email checked automatically when leaving the field.
  • No duplicate DNIs are allowed.

8. Security & Integrity

Every operation updates the DVH/DVV and logs an event entry. Passwords are stored as SHA-256 encrypted hashes for security.

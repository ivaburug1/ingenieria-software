👤 Ayuda - Gestión de Usuarios

1. Objetivo del formulario

Este módulo permite gestionar los usuarios del sistema AseguraYa: creación, modificación, activación/desactivación, desbloqueo y asignación de roles. También permite aplicar filtros para visualizar usuarios según su estado o rol.

2. Crear Usuario

  • Presioná “Crear” para entrar en modo creación.
  • Completá los campos:
    • DNI: solo números.
    • Apellido/s y Nombre/s: solo letras.
    • Email: debe tener un formato válido.
    • Rol: seleccioná uno del menú desplegable.
  • Luego hacé clic en Aplicar para guardar el nuevo usuario.
💡 El sistema genera automáticamente el usuario (nombre.apellido) y la contraseña inicial (dni.apellido), la cual se guarda encriptada con SHA-256.

3. Modificar Usuario

  • Seleccioná un usuario de la tabla.
  • Presioná “Modificar” y editá los datos habilitados.
  • Confirmá los cambios con Aplicar.
⚙️ El campo DNI no puede editarse para mantener la integridad del registro. Los cambios se registran automáticamente en los eventos del sistema.

4. Desbloquear Usuario

  • Seleccioná un usuario bloqueado (tras tres intentos fallidos de inicio de sesión).
  • Presioná “Desbloquear” y luego Aplicar.
  • El sistema reestablece la contraseña por defecto y permite el acceso nuevamente.
🔐 El usuario deberá cambiar su contraseña al ingresar la próxima vez.

5. Activar / Eliminar Usuario

  • Seleccioná el usuario deseado.
  • Presioná “Activar / Eliminar” y luego Aplicar.
  • El cambio es lógico: el usuario no se borra físicamente de la base, solo cambia su estado.
⚠️ Los usuarios desactivados no pueden iniciar sesión hasta ser reactivados.

6. Filtrar Usuarios

  • Utilizá los menús superiores para aplicar filtros:
    • Activados/Desactivados — muestra usuarios activos o inactivos.
    • Usuarios bloqueados — muestra usuarios con acceso restringido.
    • Rol — filtra por tipo de rol asignado.
  • Presioná Filtrar para aplicar las condiciones.

7. Validaciones automáticas

  • Los campos DNI, Apellido y Nombre se validan en tiempo real.
  • El correo se valida con expresiones regulares al salir del campo.
  • No se permite duplicar usuarios con el mismo DNI.

8. Seguridad e integridad

Cada acción recalcula el DVH/DVV del módulo y genera un registro en la bitácora de eventos. Además, las contraseñas se almacenan con encriptación SHA-256 para garantizar la seguridad.

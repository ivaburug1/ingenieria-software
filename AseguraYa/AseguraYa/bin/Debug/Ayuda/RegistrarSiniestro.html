🧾 Ayuda - Registrar Siniestro

1. Propósito del formulario

El formulario Registrar Siniestro permite registrar un evento o accidente que involucra una póliza activa en el sistema AseguraYa. Aquí se cargan los datos del siniestro, incluyendo fecha, valores económicos y cobertura afectada.

2. Estructura de la pantalla

  • Número de póliza: campo donde se ingresa la póliza afectada. Solo se permiten números.
  • Buscar: verifica que la póliza exista y carga automáticamente las coberturas disponibles.
  • Fecha: calendario para seleccionar la fecha en la que ocurrió el siniestro.
  • Valor del bien: monto total del bien asegurado o afectado.
  • Valor de reparación: monto estimado del costo de reparación o indemnización.
  • Coberturas: lista desplegable de las coberturas asociadas a la póliza.
  • Registrar: confirma la carga del siniestro en la base de datos.

3. Proceso de registro

  1. Ingresar el Número de póliza y presionar Buscar.
  2. Si la póliza existe, se habilitarán las coberturas relacionadas.
  3. Completar los campos Fecha, Valor del bien, Valor de reparación y seleccionar la cobertura correspondiente.
  4. Presionar Registrar para guardar el siniestro.
  5. El sistema generará un documento con los datos del siniestro y actualizará los dígitos verificadores (DVH/DVV).
💡 Consejo: asegurate de presionar el botón “Buscar” antes de registrar el siniestro. Si no lo hacés, el sistema no permitirá completar la operación.

4. Validaciones y errores comunes

  • El número de póliza debe contener solo números.
  • Los valores del bien y reparación deben ser decimales válidos (por ejemplo, 1234.50).
  • Debe seleccionarse una cobertura válida antes de registrar.
  • No se permiten campos vacíos.

5. Auditoría y trazabilidad

Cada registro de siniestro queda guardado con la fecha, el usuario y los datos del evento. Además, se genera un informe automático en PDF y se registra un evento en la bitácora del sistema.

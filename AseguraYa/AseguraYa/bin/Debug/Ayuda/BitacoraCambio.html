📘 Ayuda - Bitácora de cambios

1. Propósito del formulario

La Bitácora de cambios permite visualizar, filtrar y restaurar registros de clientes modificados o dados de baja en el sistema. Sirve como herramienta de auditoría y control de versiones de datos.

2. Estructura de la pantalla

  • Cuadro principal: muestra todos los registros históricos de clientes (versión, estado, fecha y datos asociados).
  • DNI: permite filtrar los registros por número de documento.
  • Fecha desde / hasta: permite acotar el rango temporal de búsqueda.
  • Botones:
    • Filtrar: aplica los filtros seleccionados.
    • Limpiar filtro: vuelve a mostrar todos los registros.
    • Volverlo vigente: reactiva una versión anterior del cliente seleccionada.
💡 Consejo: podés combinar los filtros de DNI y Fechas para acotar los resultados con precisión.

3. Filtro por criterios

  • Ingresá un DNI válido para mostrar solo los registros del cliente correspondiente.
  • Podés filtrar por fechas utilizando las opciones Desde y Hasta.
  • El botón Filtrar actualizará los datos visibles en la grilla.

4. Restauración de un cliente

Si un cliente fue modificado o eliminado, podés seleccionarlo en la grilla y presionar “Volverlo vigente”. El sistema marcará esta versión como activa y desactivará cualquier otra copia anterior.

⚠️ Solo se puede tener una versión activa del mismo cliente (DNI) a la vez.

5. Integridad de datos

Cada acción de restauración o modificación se registra automáticamente en la bitácora de eventos del sistema. Esto garantiza trazabilidad completa de los cambios y mantiene la consistencia de la base de datos.

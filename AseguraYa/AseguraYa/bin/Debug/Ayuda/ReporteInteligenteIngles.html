📈 Help - Recommendation of Increase

1. Purpose of this form

The Recommendation of Increase form is used to analyze clients with a high number of claims and, when appropriate, apply a percentage increase to their monthly policy premium. It also allows filtering results and exporting the current view to a PDF report.

2. Screen structure

  • Filters area (top): Allows you to narrow down the list of clients:
    • DNI: filters by client ID number.
    • Cuota Desde / Cuota Hasta: defines a range for the monthly premium.
    • Cantidad de Siniestros: minimum number of claims for the client.
    • Buttons “Filtrar” and “Limpiar Filtro”: apply or reset filters.
  • Main grid: Displays the result set returned by the system. Typical columns:
    • DNI
    • Client name
    • Policy number
    • Current monthly premium
    • Number of claims
  • Action buttons (bottom):
    • Aumentar Cuota: applies a percentage increase to the selected client’s premium.
    • Imprimir: generates a PDF report with the current grid view.
💡 Tip: Use the filters to focus on clients with the highest risk (for example, higher premium and higher number of claims) before applying any increase.

3. How to apply a premium increase

  • Select one row in the main grid (one client/policy).
  • Click “Aumentar Cuota”.
  • The system will ask for a percentage (e.g., 10 for a 10% increase).
  • If the value is not numeric, an error message will be shown.
  • After entering a valid percentage, a confirmation window shows:
    • DNI
    • Policy number
    • Current premium
    • Increase percentage
    • New premium
  • If you confirm, the system updates the policy premium and recalculates the verification digits (DVH/DVV) for the policy table.
  • The grid is refreshed automatically with the updated values.
⚠️ If no row is selected, the system will show a message asking you to select a client before applying an increase.

4. Filtering and clearing results

  • Use DNI to find a specific client.
  • Use Cuota Desde / Hasta to restrict the premium range.
  • Use Cantidad de Siniestros to focus on clients with more claims.
  • Click “Filtrar” to apply all criteria together.
  • Click “Limpiar Filtro” to reset all fields and reload the default data set.

5. Exporting the recommendation report to PDF

When pressing “Imprimir”, the system generates a PDF file on your Desktop, including all rows currently displayed in the grid. The report contains:

  • A title and the name of the system (AseguraYa).
  • The generation date and time.
  • A table with the same columns and values shown on screen.
📂 The file name includes the current date and time, making it easy to archive different reports over time.

6. Data validation and messages

  • DNI, Cuota Desde, Cuota Hasta and Cantidad de Siniestros only accept numeric values. If you type letters or symbols, the system cleans the field and shows a warning message.
  • If the percentage entered for the increase is not valid, the system shows an error and does not apply any change.
  • If an unexpected error occurs while generating the PDF, an error message is displayed with technical details.

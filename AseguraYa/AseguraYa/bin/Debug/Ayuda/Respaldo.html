💾 Ayuda - Gestión de Respaldo

1. Propósito del formulario

La ventana de Gestión de Respaldo permite realizar copias de seguridad y restauraciones de la base de datos del sistema AseguraYa. Su objetivo es preservar la integridad de la información y garantizar la recuperación ante fallos.

2. Estructura de la pantalla

  • BackUP: crea un respaldo completo de la base de datos en un archivo .bak.
  • Restore: permite restaurar un respaldo previo seleccionando el archivo correspondiente.

3. Proceso de Backup

  • Al presionar BackUP, se abre una ventana para elegir dónde guardar el archivo.
  • El sistema genera un archivo con el formato BCK_AAAAmmdd_HHmmss.bak.
  • El evento queda registrado automáticamente en la bitácora de auditoría.
💡 Consejo: guardá los respaldos en un directorio seguro o externo para mayor protección.

4. Proceso de Restore

  • Presioná Restore y seleccioná el archivo de respaldo .bak que deseas restaurar.
  • El sistema reemplazará los datos actuales con los del respaldo elegido.
  • Una vez finalizado, se mostrará un mensaje confirmando la restauración exitosa.
⚠️ Advertencia: al restaurar, los datos actuales serán reemplazados por los del respaldo seleccionado.

5. Registro y trazabilidad

Cada operación de respaldo o restauración se registra automáticamente con la fecha, el usuario y el tipo de acción, garantizando la trazabilidad completa de las copias de seguridad del sistema.

📘 Help - Change Log

1. Purpose of this form

The Change Log allows you to view, filter, and restore records of clients that have been modified or deactivated in the system. It serves as a tool for auditing and version control of customer data.

2. Screen structure

  • Main grid: displays all historical client records (version, status, date, and associated data).
  • DNI: filters the records by client ID number.
  • From / To dates: limits the search to a specific time range.
  • Buttons:
    • Filter: applies the selected filters.
    • Clear filter: resets the grid to show all records again.
    • Make active: restores a previous version of a client record and sets it as active.
💡 Tip: you can combine DNI and Date filters to narrow down your search more precisely.

3. Filtering by criteria

  • Enter a valid DNI to display only the records of that client.
  • You can filter by date using the From and To fields.
  • Click Filter to update the grid according to the selected criteria.

4. Restoring a client

If a client has been modified or deleted, select it from the grid and click “Make active”. The system will mark this version as active and deactivate any other previous copies.

⚠️ Only one active version per client (DNI) can exist at a time.

5. Data integrity

Every restoration or modification is automatically recorded in the system’s event log. This ensures full traceability of changes and maintains data consistency across the database.
